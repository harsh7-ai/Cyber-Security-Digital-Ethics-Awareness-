🔐 Cyber Security & Digital Ethics Awareness

Fundamentals of Computing and Digital Ethics

Welcome to my Cyber Security and Digital Ethics Awareness project!

This project aims to spread awareness about online safety, cyber threats, digital privacy, and the responsible use of technology.

🎯 Objectives

- Understand the basics of cyber security.
- Learn how to create stronger passwords.
- Identify common online scams and phishing attempts.
- Understand digital ethics and online privacy.
- Promote responsible internet usage.

📚 Topics Covered

1. Cyber Security

Learn about cyber threats, malware, phishing, and basic security practices.

2. Password Safety

Understand password strength and the importance of protecting account credentials.

3. Online Privacy

Learn how to protect personal information while using websites and applications.

4. Digital Ethics

Explore responsible technology use, respect for intellectual property, and online behaviour.

5. Safe Internet Usage

Discover practical ways to browse safely and recognize suspicious messages.

🐍 Python Mini Project

Password Strength Checker

A simple Python program that evaluates basic password characteristics and provides general password safety guidance.
